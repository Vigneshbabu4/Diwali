# Diwali Wishes (frontend)
React + Vite. Run: `npm install && npm run dev`. Build: `npm run build` (output: `dist`).
Deploy: Vercel (import repo, root dir `frontend`) or Netlify (base dir `frontend`, publish `dist`).

## Music
A traditional-style (Raga Bhoopali) background track is generated in the browser and starts on the visitor's first tap
(browsers block autoplay). To use your own song, add it as `public/bgm.mp3`; it is picked up automatically.
